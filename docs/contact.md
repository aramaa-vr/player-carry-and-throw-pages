# 不具合・不明点のお問い合わせ

導入や操作で分からないこと、不具合の報告は、Discord「あらまあ素敵なショップ」の問い合わせチャンネルへお寄せください。ワールドで遊ぶ方・ワールド制作者のどちらもご利用いただけます。

<div class="action-row"><a class="primary" href="https://discord.gg/BJ3BpVnMna" target="_blank" rel="noopener noreferrer">Discordで問い合わせる（別タブ）</a></div>

<div class="contact-guide">
  <div>
    <ol>
      <li>上のリンクからDiscordサーバーに参加します。</li>
      <li>チャンネル一覧の「交流・お問い合わせ」を開きます。</li>
      <li>「📩┃問い合わせ┃」でご相談ください。</li>
    </ol>
    <p>分かる範囲で、次の情報を添えていただくと状況を確認しやすくなります。</p>
    <ul>
      <li>分からないこと、または起きた現象と期待した動作</li>
      <li>現象が起きるまでの手順・使用しているモード</li>
      <li>利用環境（PCのDesktop／PCVR／Questなど）</li>
      <li>可能であれば、画面の画像や動画、表示されたエラー</li>
    </ul>
    <p>ワールド制作者の方は、使用中のパッケージ・Unity・Worlds SDKのバージョンも、分かる範囲でお知らせください。</p>
  </div>
